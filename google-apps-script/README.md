# Заявки с сайта → Google Таблица

Сайт отправляет копию каждой заявки в таблицу до того, как откроется WhatsApp. Так заявка сохраняется, даже если человек передумал отправлять сообщение.

## Установка (один раз, ~5 минут)

1. Создать Google Таблицу (например, «GR Production — заявки»).
2. В таблице: **Расширения → Apps Script**.
3. Удалить всё в файле `Code.gs` и вставить содержимое `leads.gs` из этой папки. Сохранить.
4. Сверху выбрать функцию **setup** → **Выполнить**. Google попросит доступ к таблице — разрешить (может появиться предупреждение «приложение не проверено»: «Дополнительно» → «Перейти»).
5. **Развернуть → Новое развертывание** → тип **Веб-приложение**:
   - Выполнять от имени: **Меня**
   - У кого есть доступ: **Все**
6. Нажать **Развернуть** и скопировать адрес веб-приложения (заканчивается на `/exec`).
7. Вставить адрес в `assets/site.js` в поле `leadsEndpoint` (или прислать его — вставлю сам).

Проверка: открыть адрес `/exec` в браузере — должно показать `{"ok":true,...}`. Функция **testLead** добавляет в таблицу тестовую строку.

## Что получится в таблице

Лист «Заявки»: дата, статус (выпадающий список с цветом строки), имя, страница, кто (агентство/владелец/застройщик), что снимаем, формат и сумма, где объект, сообщение, язык, UTM-метки, устройство, откуда пришёл, ID заявки (тот же ID стоит в сообщении WhatsApp), fbp/fbc для будущей передачи событий в Meta по API, комментарий.

Письмо о каждой новой заявке: вписать адрес в `NOTIFY_EMAIL` в начале скрипта и сделать новое развертывание (см. ниже).

## Если меняется скрипт

**Развернуть → Управление развертываниями → ✏️ → Версия: новая → Развернуть.** Адрес `/exec` остаётся прежним, на сайте ничего менять не нужно.

## Заявки в Telegram

1. В Telegram открыть **@BotFather** → `/newbot` → придумать имя и username (должен заканчиваться на `bot`). BotFather пришлёт **токен** вида `123456789:AA...`.
2. Кто получает заявки:
   - лично: каждый получатель открывает бота и нажимает **Старт**;
   - или группа: создать группу, добавить туда бота, написать в группе `/start`.
3. В Apps Script вставить новую версию `leads.gs`, сохранить.
4. ⚙️ **Настройки проекта → Свойства скрипта → Добавить свойство**: `TG_TOKEN` = токен. Токен не вставляется в код и никуда не пересылается.
5. Выбрать функцию **connectTelegram** → **Выполнить** → разрешить доступ (Google спросит про «внешние сервисы»). В каждый подключённый чат придёт «✅ Бот подключён».
6. **testTelegram** → пришлёт пример заявки.
7. **Развернуть → Управление развертываниями → ✏️ → Версия: новая → Развернуть.** Без этого сайт продолжит работать со старой версией скрипта.

Добавить ещё одного получателя: он нажимает «Старт» в боте, затем снова запустить **connectTelegram**. Если Telegram недоступен, заявка всё равно сохраняется в таблицу и уходит на почту.
